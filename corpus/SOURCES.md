All files in `fixtures/` are written for this project (MIT). Several re-implement, in our own code, the patterns described on the TradingView repainting page (https://www.tradingview.com/pine-script-docs/concepts/repainting/); the docs' own example code was **not** copied because the docs carry no explicit open-source license.

## Considered and skipped

- `Ahmed-GoCode/Quant-Edge-Indicators`: GitHub shows MPL-2.0 metadata, but the LICENSE file says "All rights reserved" → unclear, skipped.
- `everget/tradingview-pinescript-indicators`, `pinecoders/pine-utils` (GPL-3.0): skipped to keep the repo free of GPL test data.
- `LuxAlgo/PineTS` (AGPL-3.0): skipped.
- `hasnocool/tradingview-pine-scripts` (GPL-3.0): skipped, even where individual scripts carry an MPL header inside a GPL repo.
- `MeridianAlgo/Pine-A-Script`: repo LICENSE is MIT, but the scripts that use `varip` / `timenow` / `alert` are attributed to other authors (jjart, Trade with Dhruv, EdgeTools, traderschatroom88) without a permissive header → unclear, skipped.
- `yusin99/Tradingview-Indicator---Pivots-and-Killzones`: repo LICENSE is MIT, but `script.pine` has no license header and matches a widely republished ICT script → unclear, skipped.
- `krosenfeld7` scripts that do not carry the author's own MPL-2.0 header: skipped. `{{timenow}}` inside alert-message strings was not treated as a `timenow` use.
- `TradersPost/pinescript`, `vitopod/four-state-pine`, `Al0010/grid-spot-algorithm-trading`: no LICENSE file → skipped.
- TradingView public library scripts: per-script licenses vary and scraping TradingView is against its ToS → not collected.
